# Administration scripts

Tenant-level and governance tasks. These call the Power BI **admin** APIs and therefore
require the Fabric Administrator or Power BI Administrator role, or a service principal
that the tenant has enabled for admin API access.

Open a tool's folder, read its README, and download its `.cmd` file.

| Tool | Answers |
|---|---|
| [PowerBI-Lineage](PowerBI-Lineage/) | Which database, schema and table feeds every report, through which semantic model and gateway. Excel output. |
